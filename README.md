# realty_smart_lead

Сайт-визитка: автоматизация бизнеса.

**Сайт:** https://spaidermen4k.github.io

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `index.html` | Содержимое страницы: тексты, блоки, ссылки |
| `style.css` | Внешний вид: цвета, шрифты, отступы, мобильная версия |
| `script.js` | Поведение страницы (сейчас — год в подвале) |

Сайт публикуется бесплатно через GitHub Pages: любое изменение, отправленное в ветку `main`, появляется на сайте через минуту-две.
